# 0. 사전 준비
  - 이 문서에서 정의하는 Mirror 서버는 Oregon Mirror 서버입니다. 팀시티에서는 아래 메뉴들을 사용합니다.
  - Oregon Mirror 서버에 접속 가능한 클라이언트는 다음과 같습니다.
  - 이 문서는 바이너리 프리징 이후에 점검 QA, 버그픽스를 진행하기 위한 내용을 포함합니다.
# 1. 서버 빌드
  - 서버 수정 리비전이 있으면 실행해주시면 됩니다.
  - (팀시티) Server_Mirror > OregonGameServer > Build > Run 을 실행합니다.
  - Success가 뜨면 빌드 에러없이 배포프로세스까지 실행은 되었습니다.
  - RESU 빌드 알리 채널에 알림으로 확인하셔도 됩니다.
# 2. 구글 버그픽스 빌드 (AOS)
  - 해당 빌드는 클라이언트 코드 수정에 의한 빌드입니다. 
  - 리소스가 수정된 내역이 있다면 리소스 빌드도 필요합니다. 
  - (팀시티) Client_Mirror> Mirror_Google > Bugfix > Run 
  - RESU 빌드 알림 채널에 알림을 확인해주세요.
  - 빌드가 완료되면 다운로드 받아서 접속 테스트를 합니다.
# 3. 애플 버그픽스 빌드 (iOS)
  - 해당 빌드는 클라이언트 코드 수정에 의한 빌드입니다. 
  - 리소스가 수정된 내역이 있다면 리소스 빌드도 필요합니다. 
  - 버전 변경 주의 사항
  - 버전 변경 방법
  - (팀시티) Client_Mirror> Mirror_Apple > Bugfix > Run 옆에 커스텀 Run 을 누릅니다.
  - RESU 빌드 알림 채널에 알림을 확인해주세요.
  - 빌드가 완료되면 테스트 플라이트에 자동으로 등록됩니다.

# 6. 참고 자료
  - 버전 표기 규칙 
  - STRAT-버전 표기 규칙-101125-144421.pdf
    - 각 항목은 다음을 의미합니다. 
      - Mirror_Google : 애니플렉스 구글 빌드
      - Mirror_OneStore : 애니플렉스 구글과 거의 동일하지만 테스트용
      - Mirror_Apple : 애니플렉스 애플 빌드
      - Mirror_GoogleJoy : 조이시티 구글 빌드
      - Mirror_AppleJoy : 조이시티 애플 빌드
      - 통상적으로 AOS 는 Mirror_Google, iOS 는 Mirror_Apple 를 전달합니다.
    - DB 패치가 필요 할 수 도 있습니다.
    - 보통은 클라이언트 빌드가 완료된 후에 빌드하는 걸로 확인됩니다.
    - 해당 채널이 없는 경우 데브옵스팀 임재욱님께 문의해주시면 됩니다.
    - (팀시티) Client_Mirror > Mirror_Google > Resource > Pending리비전 중 리소스가 있는지 확인
    - 빌드 에러 발생 시 대응 방법 
    - (팀시티) Client_Mirror > Mirror_Apple > Resource > Pending리비전 중 리소스가 있는지 확인
    - iOS 는 테스트 플라이트에 등록을 하기 때문에 버전을 체크해야합니다. 아래 버전 관리 시트로 확인해주시면 됩니다.
    - iOS 버전 관리 시트 
    - 마지막 빌드된 라이브의 버전을 확인합니다. 
      - 애니플렉스 / 조이시티 버전 별개로 동작합니다. 조이시티도 빌드가 필요하다면 같은 버전으로 맞춰주는게 좋습니다.
      - 1.8.7 (13) 에서 1.8.7은 버전, (13)은 번들버전으로 명명합니다.
      - 라이브 빌드가 릴리즈 되면 해당 버전은 사용할 수 없습니다.
      - 위 이미지를 보면서 설명하겠습니다.
    - 버전 관리 시트에 버전을 추가했다면 빌드를 진행합니다.
    - 버전은 빌더에서 관리합니다. 
    - 인스펙터에서 수정 후 저장 / 커밋
      - 애니플렉스 애플 : ios_mirror_apple
      - 조이시티 애플 : ios_mirror_applejoy
      - 트렁크에서 수정하여 해당 브런치에서 머지, 커밋해주시면 됩니다.
    - Parameter 탭을 선택 > Bundle Version 을 입력합니다.
    - Run Build 
    - 등록까지 시간이 소요되며 테스트 플라이트를 설치해두셨다면 설치 가능 시점에 자동으로 알림이 옵니다.
    - 아래 리스트의 인원들만 자동으로 등록됩니다. (애니플렉스)
      - 내부테스터로 등록하려면 김원태님을 통해 애니플렉스 측에 요청해주시면 됩니다.
      - 이후 아래 그룹에 추가해주시면 됩니다.
    - 필요시 조이시티 빌드도 전달합니다.
